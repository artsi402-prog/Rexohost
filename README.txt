RexoHost v1 — démonstration statique
=====================================
Fichiers:
- index.html : site vitrine + espace client de démonstration, tout-en-un.

Tester sur téléphone:
1. Ouvre index.html dans un navigateur ou prévisualise-le avec un éditeur HTML.
2. Les boutons du panel sont simulés. Il n'y a ni compte réel, ni base de données, ni serveur Minecraft.
3. Ne collecte pas de mots de passe et ne présente pas les offres comme disponibles à l'achat.

Publication gratuite suggérée:
- GitHub Pages: https://docs.github.com/en/pages/getting-started-with-github-pages
- Cloudflare Pages (upload direct): https://developers.cloudflare.com/pages/get-started/direct-upload/

Un domaine rexohost.be peut coûter de l'argent; commence avec le sous-domaine fourni par l'hébergeur gratuit.
Le vrai panel Pterodactyl demande un serveur Linux et des compétences d'administration:
https://docs.pterodactyl.io/v2/panel/getting-started
